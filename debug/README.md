Các thư mục debug lưu tạm scripts fetch docs, gọi API test, và log chạy thử.

Cấu trúc hiện tại:
- api/: script gọi trực tiếp Zalo Bot API
- docs/: file HTML export tài liệu Zalo Bot Platform
- generated/: scripts sinh code tạm dùng khi PowerShell mất template literals
- logs/: file log chạy test polling

Không commit nội dung trong thư mục này.
